RED SMS · Python
================

Требуется Python 3.8 или новее. Из корня репозитория::

    python3 -m venv .venv
    .venv/bin/python -m pip install .
    cp samples/config.json.dist samples/config.json

Для Windows используйте python из .venv/Scripts. В config.json укажите логин,
API-ключ, свой номер и зарегистрированные имена отправителей.

Проверка доступа и списка отправителей::

    .venv/bin/python samples/get_info.py
    .venv/bin/python samples/get_sender_name_list.py

Отправка одного платного SMS и проверка статуса::

    .venv/bin/python samples/send_sms.py

Скрипты send_viber.py и resend_sms_viber.py требуют подключенного канала Viber.
send_dispatch.py создаёт рассылку. Запускайте эти примеры с разрешёнными
для аккаунта именами и тестовым номером.

Документация: https://docs.redsms.ru/http/

Ошибки при отправке SMS
-----------------------

HTTP 200 означает, что создано хотя бы одно сообщение. Сохраните UUID из items и проверьте errors для остальных номеров.
При HTTP 400 проверьте параметры, дубликаты и лимиты. При 401 проверьте подпись и разрешённые IP.
При 404 проверьте путь без завершающего слеша, а для проверки статуса также UUID.
При 420 проверьте баланс. В зависимости от настроек аккаунта недостаток средств может проявиться и после создания сообщения статусом no_money.
При HTTP 500 или сетевом тайм-ауте результат отправки может быть неизвестен. Автоматический повтор POST может создать дубликат.

SMS-пример выводит статус по каждому UUID. При created, progress и moderation он проверяет статус ещё раз через 10 секунд.
Если обработка продолжается, сохраните UUID для следующего запроса. Для постоянной интеграции доступны webhook-уведомления.
Справочник статусов и поля errCode: https://docs.redsms.ru/http/api/message/
